Ce qui est repris

La ligne d'en-tête POSTE · DESCRIPTION · Qté · UNITE · PRIX est retrouvée toute seule. « LOT n » → un titre (lot) ; un numéro (2.1) ou un texte en MAJUSCULES → un sous-titre ; un autre texte → une ligne de texte ; une quantité → un poste. « option » → la description commence par « Option : ».
